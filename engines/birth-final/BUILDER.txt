BUILDER QUICK START (5 minute)
==============================
1. Node.js LTS install koro (https://nodejs.org). Tarpor TERMINAL-E
   EI FOLDER-E ASHO (path dite hobe - na hole command kaj korbe na):
     a) Folder kholo -> address bar-e click kore cmd likhe Enter,  OR
     b) PowerShell-e:  cd "C:\path\to\BDRIS-Engine"
   Tarpor (1 bar):
     npm install
   (puppeteer Chrome auto download hobe)
   MONE RAKHO: nicher shob node/npm command EI folder-e boshe chalaba.

2. CHECK (server lagbe na):
   check.html double-click -> shob green PASS ashte hobe.
   cert-engine-standalone.js doubt hole:
     node -e "require('./cert-engine-standalone.js').selftest()"
   SERVER CHECK (server chaliye): check-api.html double-click ->
   "Run all checks" -> 6/6 PASS (store, captcha, engine, preview,
   PDF, records - shob birth). Manual verify box-e real record diyeo
   test kora jay.

3. USE (tomar code theke, 1 call):
   const CE = require('./cert-engine-standalone.js');   // shudhu codes (QR/barcode/key)
   const r = await CE.build({ number: '20008812737140064' });

   const builder = require('./certificate-builder');    // puro certificate
   const out = await builder.buildCertificate(record);  // {html, png, pdf}
   // (BIRTH only - death certificate alada project: death-certificate/)

   const wf = require('./workflow-engine');             // record + save shoho
   const done = await wf.createRecord({ number, name, url, data });

4. RUN (Studio UI):
   Windows: start.bat double-click  (ba: node server.js)
   Browser: http://localhost:3000

5. ORACLE (record save):
   ORACLE_CONN_STR=host:port/service + ORACLE_USER + ORACLE_PASSWORD
   set kore server chalao; table auto-create hobe. Na thakle file-e save hoy.

6. TROUBLESHOOT (2 common problem):
   a) FONT: install korte HOBE NA — certificate fonts ALREADY EMBEDDED
      (assets/fonts.css, base64 woff2). Sob PC-te same render, kintu
      notun server.js + assets/fonts.css thakbe — purono copy-e NOTUN
      files copy koro. (SutonnyOMJ.ttf alada dorkar nei.)
   b) PDF 3MB+ hoye gele = purono raster path (nosto). Notun code-e VECTOR PDF
      default — shobshomoy code theke nao:
        const out = await builder.buildCertificate(record);
        require('fs').writeFileSync('cert.pdf', out.pdf);
      Output: ~475 KB, text selectable, A4, pixel-perfect.
      (Purono file-e 3MB dekhle = notun server.js/certificate-builder.js niye
      abar npm install + abar generate koro.)
