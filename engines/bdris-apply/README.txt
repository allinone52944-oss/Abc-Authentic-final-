================================================================
 BDRIS Auto-fill Bot v3 — README
================================================================
bdris.gov.bd পোর্টালে জন্ম নিবন্ধন ফর্ম স্বয়ংক্রিয়ভাবে পূরণ ও জমা
করার ডেস্কটপ টুল (Node.js + Playwright + Socket.IO)।

v3: আসল BDRIS সাইটের লাইভ ফর্ম-ম্যাপিং অনুযায়ী তৈরি — প্রতিটি
ধাপের আসল field-name/id, Verify gate, ডকুমেন্ট modal সহ।

----------------------------------------------------------------
 ১) Node.js ইনস্টল করুন (শুধু প্রথমবার)
----------------------------------------------------------------
 - https://nodejs.org থেকে "LTS" ভার্সন ডাউনলোড করে ইনস্টল করুন।
 - ইনস্টল শেষে কমান্ড প্রম্পটে লিখে চেক করুন:
     node --version

----------------------------------------------------------------
 ২) এই ZIP ফাইলটি Extract করুন
----------------------------------------------------------------
 - যেকোনো ফোল্ডারে Extract করুন, যেমন: C:\Bdris-apply-v3
 - ফোল্ডারের ভেতরে থাকবে: backend\ , frontend\ , tools\

----------------------------------------------------------------
 ৩) start-windows.bat ডাবল-ক্লিক করুন — আর কিছু করতে হবে না
----------------------------------------------------------------
 - Node.js না থাকলেও .bat নিজে ইনস্টল করে নেবে (winget দিয়ে)।
 - প্রথমবার চালালে নিজে নিজে npm install + Playwright browser
   (~170 MB, একবারই) ডাউনলোড করবে — ইন্টারনেট লাগবে।
 - ব্রাউজার নিজে নিজে http://localhost:3000 খুলে যাবে।
 - কালো উইন্ডোতে "BDRIS Automation Server v3 চালু!" লেখা
   আসলে সার্ভার রেডি।

  (হাতে চালাতে চাইলে:)
     cd backend
     npm install
     npx playwright install chromium
     npm start

----------------------------------------------------------------
 ৪) ব্রাউজারে খুলুন — আসল ৫ ধাপ
----------------------------------------------------------------
 - http://localhost:3000
 - বট স্বয়ংক্রিয়ভাবে BDRIS পোর্টাল খুলবে (আলাদা Chrome উইন্ডো)।
 - ডান পাশে "বট লাইভ ফিড"-এ বটের প্রতিটি কাজ লাইভ দেখা যাবে।

   ধাপ ১ — আবেদনের ভিত্তি: জন্মস্থান / স্থায়ী ঠিকানা (+ দূতাবাস)।
   ধাপ ২ — ব্যক্তির পরিচিতি: নাম (প্রথম/শেষ অংশ, বাংলা+ইংরেজি),
            জন্ম তারিখ, কততম সন্তান, লিঙ্গ, দেশ → জন্মস্থানের
            ঠিকানা (বিভাগ → জেলা → সিটি/উপজেলা → পৌরসভা/ইউনিয়ন
            → ওয়ার্ড → ডাকঘর → গ্রাম)।
   ধাপ ৩ — পিতামাতা: BRN (১৭ ডিজিট, বাধ্যতামূলক) + জন্ম তারিখ +
            নাম + জাতীয়তা। বট Verify বাটনে ক্লিক করে BRN যাচাই
            করবে — ভুল BRN-এ এগোনো যায় না, বট জানিয়ে দেবে।
   ধাপ ৪ — ডকুমেন্ট: ধরন বেছে ফাইল যোগ করুন।
   ধাপ ৫ — চূড়ান্ত যাচাই: সব তথ্য একবার দেখে নিন → "OTP ধাপে
            যান" → মোবাইল নম্বর + ৬-বক্স OTP → জমা।
 - সাফল্যের পর আবেদন নম্বর + স্ক্রিনশট দেখাবে।

----------------------------------------------------------------
 ৫) দরকারি তথ্য
----------------------------------------------------------------
 - খসড়া অটো-সেভ: টাইপ করা তথ্য ব্রাউজারে সংরক্ষিত থাকে;
   পেজ রিফ্রেশ করলেও হারায় না।
 - কোনো ফিল্ড বট পূরণ করতে না পারলে হলুদ বক্সে তালিকা দেখাবে —
   বটের উইন্ডোতে ম্যানুয়ালি ঠিক করে পরের ধাপে যান।
 - ৪৫+ দিন বয়সী শিশুর ক্ষেত্রে BDRIS "ডকুমেন্ট আছে কিনা"
   জিজ্ঞেস করে — বট স্বয়ংক্রিয়ভাবে "আছে" নিশ্চিত করে।
 - ২৫ মিনিট নিষ্ক্রিয় থাকলে বট নিজে নিজে বন্ধ হয়ে যাবে।
 - সার্ভার স্বাস্থ্য: http://localhost:3000/api/health

----------------------------------------------------------------
 ৬) অপশনাল সেটিংস (advanced)
----------------------------------------------------------------
 backend ফোল্ডারে .env ফাইল বানিয়ে (যেকোনো লাইন বাদ দেওয়া যায়):
   PORT=3000
   BDRIS_URL=https://bdris.gov.bd/br/application
   HEADLESS=1            (1 = ব্রাউজার লুকিয়ে চালানো)
   SLOWMO=40             (কাজের মাঝে বিলম্ব, মিলিসেকেন্ড)
   SESSION_TIMEOUT_MIN=25

----------------------------------------------------------------
 ৭) টেস্ট মোড (BDRIS সাইটে না গিয়ে পরীক্ষা)
----------------------------------------------------------------
   cd backend
   set MOCK_BDRIS=1 && npm start        (Windows cmd)
   $env:MOCK_BDRIS=1; npm start         (PowerShell)
 - বট আসল সাইটের বদলে নকল BDRIS ফর্ম খুলবে — পুরো ফ্লো
   নিরাপদে পরীক্ষা করা যাবে।

----------------------------------------------------------------
 ৮) সমস্যা হলে
----------------------------------------------------------------
 - "BDRIS সাইট লোড ব্যর্থ" → ইন্টারনেট চেক করুন, ↺ রিসেট চাপুন।
 - পোর্ট 3000 ব্যস্ত থাকলে: .env-এ PORT=3001 দিয়ে চালান,
   তখন ঠিকানা হবে http://localhost:3001
 - অ্যান্টিভাইরাস ব্লক করলে: Bdris-apply-v3 ফোল্ডারটি
   exclusion-এ রাখুন।

 v4-তে নতুন:
 - বট auto-start: পেজ খুললেই বট নিজে নিজে চালু হয়ে BDRIS লোড
   করে রাখে — বসার সাথে সাথে কাজ।
 - খসড়া (Draft): OTP-এর আগে সম্পূর্ণ আবেদন সার্ভারে সংরক্ষিত
   থাকে (backend\drafts\); ধাপ ১-এর "সংরক্ষিত খসড়া" থেকে
   Resume চাপলে বট আবার পূরণ করে OTP ধাপে নিয়ে যাবে।
 - ডুপ্লিকেট সতর্কতা: BDRIS "duplicate/possible-duplicate"
   দেখালে বট আটকাবে না — স্বীকার করে এগিয়ে যাবে।
 - নামের যেকোনো চিহ্ন: বট কোনো character ফিল্টার করে না —
   তুমি যা লিখবে হুবহু বসবে।
 - সাবমিটের পর: আবেদন নম্বর বড় করে + কপি বাটন + সংরক্ষণ;
   আবেদনের মূল কপি (PDF) one-click ডাউনলোড — main server-এর
   মতো নম্বর+DOB+মোবাইল দিয়ে খোঁজা লাগবে না।
 - ২০১৩-নিয়ম verify: ২০১৩-এর আগে জন্ম হলে পিতামাতার BRN
   লাগে না, Verify বাটনও থাকে না (live-verified)।
 - ঠিকানার ধাপ: "জন্মস্থান=স্থায়ী" + "স্থায়ী=বর্তমান" টিক
   দিয়ে বট auto-fill করে।
 - প্রত্যয়ন ধাপ: আবেদনকারী (পিতা/মাতা/...) নির্বাচন +
   ঘোষণা-টিক; ডকুমেন্ট = শুধু JPG/PNG ছবি (প্রতিটি ≤2MB)।
   প্রতি ফাইলে File Type সিলেক্ট (40=ডাক্তারি/শিক্ষা সনদ,
   41=ঠিকানার প্রমাণ) + Start চাপ; ৪০ ও ৪১ দুটোই
   বাধ্যতামূলক — একটা ছাড়া BDRIS "পরবর্তী" আটকায়।
 - OTP two-phase (live-mapped): ইমেইল + মোবাইল → "ওটিপি
   পাঠান" → কোড এলে একটিমাত্র OTP বক্সে বসিয়ে "সাবমিট"।
 - 📍 ঠিকানা বই: নাম দিয়ে ঠিকানা সেভ (backend/addresses.json,
   স্থায়ী; কোনো ট্যাগ নেই)। ধাপ ২ (জন্মস্থান) ও ধাপ ৪
   (স্থায়ী/বর্তমান) — প্রতিটি ঠিকানার ঘরে ভাসমান 📍 বাটন;
   চাপলে সংরক্ষিত ঠিকানার প্যানেল — যেকোনো ঠিকানা যেকোনো
   ঘরে বসানো যায়। জন্মঠিকানা থেকে "💾 বইতে সেভ" ও যায়।
   বট BDRIS cascade দিয়েই বসায় (বিভাগ→জেলা→উপজেলা→
   ইউনিয়ন→ওয়ার্ড); কপি-টিক দিলে আগের মতো auto-copy।
 - ⚠️ সতর্কতা: "অ্যাটাচমেন্ট অ্যাভেইলেবিলিটি চেক" modal-এ
   "আমার কাছে এই ডকুমেন্টগুলি নেই" চাপলে BDRIS পুরো ফর্ম
   রিসেট করে দেয়! বট কখনো ওটা চাপে না।
