DEATH-VERIFY ENGINE — API CONTRACT (v1, Windows-only, localhost:3001)
====================================================================

RUN
  1. install.bat            (ekbar: node/python/cv2/ddddocr check + install help)
  2. start-verify.bat       (server start; port busy thakle browser khule exit 0)
     ba: node death-verify-server.js   (GEMINI_API_KEY env optional)
  Server: localhost-only (127.0.0.1:3001). Port busy hole exit code 2.
  Deps: Node.js, Python3 + opencv + ddddocr, Google Chrome (PDF-er jonno),
        curl.exe (Windows built-in), GEMINI_API_KEY (optional fallback).

ENDPOINTS (sob JSON, utf-8)
  GET  /                                UI (death-verify.html, no-store)
  GET  /health                          {"ok":true}
  GET  /api/captcha                    -> {success, sessionId, image(data-uri), diag}
  POST /api/solve-captcha   {sessionId} -> {success, answer, method:"local"|"gemini"}
  POST /api/verify  {sessionId, drn, dod, captcha}
       -> {success, data} | {success:false, error}   (captcha bhul / no record)
  POST /api/preview  {<record json>}   -> {success, html}      (death replica)
  POST /api/pdf      {<record json>}   -> application/pdf bytes (vector A4)
  GET  /api/birth-debug?drn=&dob=      (debug: birth enrichment test)

VERIFY FLOW (engine consumer)
  captcha -> solve-captcha (local; fail->gemini; fail->manual input)
        -> verify(sessionId, drn, DOD DD/MM/YYYY, captcha answer)
        -> data mile gele preview/pdf.

DATA FIELDS (data.* — khali string mane BDRIS dey ni)
  brn, nameEn, nameBn, dob(DD/MM/YYYY), dod, dodWords,
  placeOfDeathEn/Bn, causeOfDeathEn/Bn, sex,
  registrationDate, issuanceDate (DD/MM/YYYY),
  office1, office2, motherNameEn/Bn, motherNationalityEn/Bn,
  fatherNameEn/Bn, fatherNationalityEn/Bn,
  verificationUrl, recordType:"death"

AUTO-ENRICH (verify-er vitore, non-fatal — fail hole short data)
  1) KNOWN_DEATH map (server.js) — known record-er dob/key/code.
  2) Birth endpoint (/UBRNVerification/Search, curl+local captcha solve)
     — DOB janle reg/issue/dob/sex/office/nationality fill kore.
     Notun record-er DOB ajana thakle short data ashbe (error NA).

GUARANTEES / LIMITS
  - Timeouts: BDRIS 30-60s, solver 120s, Gemini 45s. Verify ~15-40s lagte pare.
  - Captcha: local (offline) -> Gemini -> manual. Kokhono hang kore na.
  - Error contract: {success:false, error:"..."} — HTTP 200/400/500/404 JSON.
  - Crash-proof: uncaught log (server.log), EADDRINUSE exit 2, single instance.
  - Fonts embedded (base64, HTML-er vitore) — render sob jaygay same.
  - Live BDRIS nirbhor: site bodlale parser vangte pare (_last-*.html debug save hoy).
